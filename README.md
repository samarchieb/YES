# YES – Yellow Energy Saving · Landing page

Site vitrine statique (HTML, CSS, JavaScript sans bibliothèque) pour YES – Yellow Energy Saving, installateur agréé ANME & STEG en Tunisie.

## Lancer le site

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec n'importe quel serveur statique.

## Structure

- `index.html` : page d'accueil
- `mentions-legales.html`, `confidentialite.html` : pages légales
- `assets/css/styles.css` : styles
- `assets/js/main.js` : interactions (simulateur, carrousels, menus, formulaires)
- `assets/img/`, `assets/video/` : visuels

## À compléter avant la mise en ligne

- Remplacer les avis d'exemple par de vrais avis clients (avec accord), signalés dans `index.html`.
- Renseigner les liens officiels Facebook, LinkedIn et YouTube.
- Faire valider les chiffres (220+ clients, 2 800 panneaux, 1,5 MWc) et les hypothèses du simulateur.
- Compresser `assets/video/hero-solaire.mp4` (≈ 17 Mo) vers 4–6 Mo.
- Brancher les formulaires sur un service d'envoi (actuellement : ouverture de la messagerie).
